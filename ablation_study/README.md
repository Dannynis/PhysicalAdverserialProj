# Ablation Study Scripts

This directory contains scripts for running ablation experiments to compare different latent sizes and training strategies.

## Quick Start

### Run a Single Experiment

```bash
# Run from the project root directory
cd /path/to/PhysicalAdverserialProj

# Run a specific experiment
python ablation_study/run_ablation_experiment.py --experiment latent_8x8

# With custom parameters
python ablation_study/run_ablation_experiment.py --experiment latent_16x16 --epochs 50 --gpu 0
```

### Run All Experiments Sequentially

```bash
python ablation_study/run_ablation_experiment.py --all
```

### Run Experiments in Parallel (Multiple GPUs)

```bash
# Automatically distributes across available GPUs
python ablation_study/run_parallel_experiments.py

# Specify which GPUs to use
python ablation_study/run_parallel_experiments.py --gpus 0 1 2 3

# Run specific experiments
python ablation_study/run_parallel_experiments.py --experiments latent_4x4 latent_8x8 latent_16x16
```

## Available Experiments

| Experiment Name | Latent Size | Rejuvenation |
|-----------------|-------------|--------------|
| `latent_4x4` | 4x4 | No |
| `latent_8x8` | 8x8 | No |
| `latent_16x16` | 16x16 | No |
| `latent_32x32` | 32x32 | No |
| `latent_16x16_with_rejuv` | 16x16 | Yes |

## Command Line Options

### run_ablation_experiment.py

```
--experiment, -e    Experiment to run (required unless --all)
--all, -a           Run all experiments sequentially
--epochs, -n        Number of training epochs (default: 30)
--batch-size, -b    Number of patches in batch (default: 10)
--gpu, -g           GPU device index to use
--output-dir, -o    Base output directory (default: ./results/ablation)
--no-comet          Disable Comet ML logging
--list              List available experiments
```

### run_parallel_experiments.py

```
--experiments, -e   Experiments to run (default: all)
--gpus, -g          GPU IDs to use (default: all available)
--epochs, -n        Number of epochs per experiment
--batch-size, -b    Batch size
--output-dir, -o    Base output directory
--no-comet          Disable Comet ML logging
--sequential        Run experiments sequentially instead of parallel
```

### analyze_results.py

```
--results-dir, -r   Directory containing experiment results
--output-dir, -o    Output directory for analysis
--compare           Specific experiments to compare
```

## Output Structure

Each experiment creates a directory with the following structure:

```
results/ablation/
├── latent_8x8_2026-01-17_12_30_00/
│   ├── latent_batch_best.pt     # Best performing latent batch
│   ├── patch_01.png             # Decoded patch images
│   ├── patch_02.png
│   ├── ...
│   ├── patch_10.png
│   ├── metadata.pkl             # Full experiment metadata (pickle)
│   ├── metadata.json            # Human-readable metadata
│   └── training_curves.png      # Training visualization
├── latent_16x16_2026-01-17_12_35_00/
│   └── ...
└── analysis/                    # Generated by analyze_results.py
    ├── summary.csv
    ├── convergence.png
    ├── loss_convergence.png
    ├── comparison_bars.png
    ├── latent_size_comparison.png
    └── rejuvenation_comparison.png
```

## Analyzing Results

After experiments complete, run the analysis script:

```bash
# Analyze all results
python ablation_study/analyze_results.py

# Analyze a specific run
python ablation_study/analyze_results.py --results-dir ./results/ablation/run_2026-01-17_12_30_00

# Compare specific experiments
python ablation_study/analyze_results.py --compare latent_4x4 latent_8x8 latent_16x16
```

## Running on Remote Server

For running on a remote server (e.g., via SSH):

```bash
# Use nohup to keep running after disconnect
nohup python ablation_study/run_parallel_experiments.py > ablation.log 2>&1 &

# Or use screen/tmux
screen -S ablation
python ablation_study/run_parallel_experiments.py
# Ctrl+A, D to detach
# screen -r ablation to reattach
```

## Metrics Tracked

- **Success Rate**: Percentage of patches that fool the classifier
- **Augmented Success Rate**: Success rate with augmentations applied
- **Loss**: Training loss (log probability of original class)
- **Epochs to 50%**: Number of epochs to reach 50% success rate
- **Best Patch Performance**: Top-5 and Bottom-3 patch rankings

## Comet ML Integration

By default, experiments are logged to Comet ML. To disable:

```bash
python ablation_study/run_ablation_experiment.py --experiment latent_8x8 --no-comet
```
